# KREA2 Batch Wild presets

These are AntiMatter Style Preset Mixer assets, copied from the source files used by `KREA2_BATCH_WILD` when the node was created. They are intentionally separate from `Style_evo`.

- One non-empty, non-comment line is one selectable preset.
- You may edit existing `.txt` files or add additional `.txt` files and subfolders.
- Restart ComfyUI after adding or renaming files so the new names appear in the node dropdowns.
